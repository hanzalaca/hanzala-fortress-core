# Contributing

Thank you for helping. Bug reports, test cases and reviews of the cryptography are the most useful contributions.

- Security problems: follow [SECURITY.md](SECURITY.md), not public issues.
- The v2 vault format is frozen until an independent review. Changes to it need a written proposal first.
- Every change needs tests, and the Swift, Kotlin and Python implementations must keep agreeing on the test vectors.
